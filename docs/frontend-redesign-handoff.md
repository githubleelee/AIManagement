## 视觉参数

- 页面背景 `#F6F8FC`；内容面板 `#FFFFFF`；主文字 `#15233B`；次级文字 `#64748B`；边框 `#E4EAF2`。
- 项目侧栏 `#17263E`；主操作蓝色 `#2563EB`；浅蓝底 `#EFF6FF`；成功绿色 `#169C72`。
- 页面内容间距 24px，主要卡片圆角 16px；控件最小高度约 44px。
- 中文字体优先 Noto Sans SC，并保留可用的系统回退字体。
- Figma 的姓名、日期、数量和任务标题仅作为视觉内容。组件必须继续使用真实数据和现有角色判断。

## 实现边界

- `docs/sprint1-spec-interface-contract.md` 决定数据与权限；Figma 决定视觉层级与间距。
- 侧栏与底部导航是同一组项目入口，不新增路由。
- 设计图展示的是数据就绪状态；空数据、加载、网络失败和无权限仍需独立可读的状态。
- 320px 和 390px 必须无页面级横向溢出；数据表可在自身容器内横向滚动。
- 键盘焦点需要可见；每个行内操作须包含行对象的可访问名称。

## 验证结果（2026-09-25）

- `npm run typecheck`、`npm run build`、`git diff --check` 通过。
- 全量 Vitest 使用单 worker 运行：46 个文件、1113 项全部通过。默认并发和 4 worker 运行曾各有一个 worker 意外退出；对应测试文件单独运行 19/19 通过。
- 浏览器登录演示项目后，检查桌面 1440px、移动 320px/390px 的概览、需求、任务和成员页面；没有页面级横向溢出。任务和成员宽表在各自容器内横向滚动。
- PM 成员页显示管理控件；VIEWER 成员页只读。浏览器控制台无错误。
