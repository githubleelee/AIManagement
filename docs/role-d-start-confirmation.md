## 4. 附件允许类型、10MB 校验点及存储位置

- **扩展名白名单**：`png` / `jpg` / `jpeg` / `webp` / `pdf` / `docx` / `xlsx` / `zip`。
- **大小限制**：服务端单文件 ≤ 10MB；扩展名与 MIME **联合校验**，不能只信前端。
- **MIME 标准值**：

| 扩展名 | MIME |
|---|---|
| png | `image/png` |
| jpg / jpeg | `image/jpeg` |
| webp | `image/webp` |
| pdf | `application/pdf` |
| docx | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
| xlsx | `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet` |
| zip | `application/zip` |

- **不扩项**：不扩 `svg` / `gif` / `doc` / `xls` / 宏 Office / 可执行 / 脚本。
- **字节口径**：若按字节数限制，使用严格 SI 10MB = 10,000,000 B，前后端一致，**不偷偷改成 10MiB**。
- **存储**：数据库存元数据，实体文件放项目根 `var/uploads/`，并加入 `.gitignore`；该目录仍在项目工作目录内，只是被 Git 忽略，**不要称其为真正仓库外**。
- **下载**：仍按任务权限判定。
- **清理**：任务成功删除后，元数据及实体文件同时清理；失败可追踪重试；**任务删除失败不能先删文件**；DB 与文件系统不保证天然原子。
- **范围外**：ZIP 作为附件不自动解压运行；不加额外杀毒 / 复杂服务范围。
