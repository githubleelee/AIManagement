## 3. 角色、敏感与撤权矩阵

每个 CRUD 和关联端点覆盖：

- PM 正常访问、创建、编辑、删除、关联。
- MEMBER 可见图读取；写入结果按最终裁决断言，不提前固定为成功或 403。
- VIEWER 可见图读取、写入 403。
- outsider 对列表、详情、写入、候选接口均 404，响应无对象字段。
- 无 token / 无效 token 返回 401。
- 敏感故事与敏感任务：授权与未授权 MEMBER、VIEWER 对照；图自身敏感策略批准后补同样覆盖。
- 共享 token 的同一会话内移除成员、取消白名单、改图关联、目标后标敏，下一次请求立即生效。
- 列表与计数同源过滤；不能通过关联数量、总数、错误信息、图标题、文档节点或链接反推隐藏对象。
- 图 id 与路由 projectId 不匹配时不返回另一项目图数据。
- 目标删除、解绑及失效引用测试按批准方案编写，特别验证不能自动降密。

## 4. 数据完整性与安全补充

- 图名空白/超长、未知图类型、未知格式版本、超限 document、错误字段类型。
- 重复节点 id、关系端点缺失、时序消息发送方/接收方缺失、非法顺序；具体限制待 C5。
- PATCH 未传字段保持不变，合并后校验；不能用未授权字段覆盖项目/作者/敏感名单。
- 图与关联原子保存，任一目标失效或不合法则整次失败，不产生半图或部分关联。
- 删除图按批准规则处理本图关系；重复删除不影响其他图或业务对象。
- HTML/script、事件属性、javascript: 链接和原始 SVG 文本不执行；图内容不外发外部渲染服务。
- 并发行为按最终批准的覆盖/版本冲突规则验证，不虚构已有乐观锁。

## 5. 浏览器走查脚本

在隔离的纯虚构演示数据中：

1. PM 登录项目，创建目标、活动、故事、任务（复用真实现有 API/UI）。
2. 新建用例图，在线编辑参与者、用例和关系，保存刷新。
3. 新建“提交任务→验收通过/驳回”核心时序图，在线编辑生命线及消息并保存。
4. 关联本项目与需求层级、任务，重开验证，点击需求及任务跳转并核对具体对象。
5. 进行跨项目关联反例，核对浏览器实际失败响应及无部分结果。
6. VIEWER 读取可见图，直接发写请求验证 403；outsider 直达页面及请求 API 验证 404。
7. 关联敏感故事/任务，切换授权和未授权账号，检查图列表、详情、候选与网络原始响应。
8. 不退出登录撤销权限，刷新/重试确认即时失效。
9. 捕获实际截图/录屏和必要脱敏网络摘要，不保存 token、真实资料或数据库文件。
