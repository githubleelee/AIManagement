## 1. 入口与项目隔离

- 从项目导航实际进入 `/projects/:projectId/uml`，核对 API 实际生产注册，而非独立 html 入口或手工测试插件注册。
- 新建两类图，四类关联均通过真实选择器选择；确认创建前不发 POST/PATCH，成功创建后采用服务器 ID。
- `?diagram=<id>` 复制/刷新可恢复同一图。跨项目图 ID、缺失 ID 均隐藏，不产生存在性差异。
- 前后端前缀只各处理一次：浏览器 `/api/...`，Vite rewrite 后后端无 `/api`。

## 2. 保存与关联草稿

- 修改节点/消息和关联选择，分别保存基本信息、图内容，验证另一部分草稿没有被覆盖。
- 选择器搜索名称/ID、同名对象由路径与 ID 区分、取消/重新选择、每类 50 上限、空项目、断网后重试。
- 真实 ID 高级输入与复选框共享同一草稿；候选之外的旧 ID 保留，不按候选列表静默清空。
- 非法/跨项目关联真实 422，保留草稿与已保存内容；失败不得展示“已保存”。
- 已保存对象名称/链接仅跟随成功保存响应；未保存选择不冒充服务器已保存关联。

## 3. 权限和不自动降密

- 普通空图与普通关联图 MEMBER/VIEWER GET 200；POST/PATCH/PUT/DELETE 不扩权。
- 关联时已敏感的 task、story 各测一张：非 PM 包括白名单成员 404；PM 可读。
- 清空关联、真实删除目标、仅改标题/内容/owner/普通关联后，历史 true 图仍 404。
- **后置敏感（须 B 补丁）**：先关联普通对象，再通过真实 sensitivity 端点标敏感。白名单成员也不可读；随后解绑/删目标/恢复普通仍不可读。task/story 两类及两种并发次序均验证。
- 非法关联/失败写事务不残留 guard 或半图。列表、total、kind 过滤、200 截断与详情一致。
- 页面失权重新鉴权后旧图、元信息、关联候选、草稿、链接均清空；不得仅禁用按钮但保留内容。

## 4. 任务行精确定位（不能只看 href）

- 点击已保存 UML 任务链接，实际到达对应故事页的**正确可见任务行**，验证行滚动并获得焦点。
- 刷新深链、同页切换不同 task hash、浏览器前进/后退、异步任务列表加载后定位。
- 未知/非法/不可见 taskId 不发额外详情请求，不显示隐藏对象名称或存在性，不焦点跳到其他行。
- 与任务编辑、附件、验收相关 UI 无回退；C 不自行加新 task route。

## 5. 交付证据与停止条件

- 每条命令独立限时、实时 UTF-8 落日志。沿用 `run-bounded.mjs`；不改共享 timeout/断言或跳过失败造绿。
- 明确区分：正式路由结果、C 隔离组件结果、历史旧基线、失败/超时/未执行。
- 全量 worker 历史异常另列；本轮限时诊断未复现 worker 异常，但超时未跑完，不可将其勾成全库通过。
