## 一、本版新增与交付的能力

### 1. 项目空间与权限
- 创建项目、自动成为项目经理；添加/移除成员、修改角色（PM / 成员 / 管理者）；不能移除自己（避免项目无 PM）。
- 项目级隔离：非项目成员访问页面或直接请求接口一律拒绝；对外**不泄漏对象存在性**。
- 对象级敏感标记 + 可见成员白名单：未授权成员在列表、详情、直接 ID 访问时都不可见、不计数。

### 2. 需求与任务
- 需求三层：业务目标 → 用户活动 → 用户故事；故事按**三段式分字段存储**（角色/能力/价值），带业务价值与优先级。
- 任务：负责人、验收人（**不得与负责人相同**，服务端硬约束）、计划起止、六状态（未开始/进行中/卡住/暂停/待验收/已验收）、进度。
- 状态语义统一：**"待验收"由负责人提交，"已验收"由验收人关闭**；两者是两个状态、两个动作人。
- 任务负责人**本人**可更新本人任务的状态与进度（本版对上一版"仅 PM 可编辑任务"口径的正式放宽，仅限本人任务；创建/编辑/删除任务与指定人员仍为 PM-only）。

### 3. 多视图与一致性
- **故事看板**：三列看板，PM 可改需求状态（唯一写路径），每次变化写审计。
- **甘特图**：需求/任务/里程碑统一时间轴，支持 **FS 前置依赖**；**前置未"已验收"时后继不允许开工**。
- **成员负载**：负载 = 负责人名下**非关闭**任务数（含待验收）；PM 看全项目，成员只看自己的可见范围。
- **仪表盘**：进度（已验收 ÷ 总数）、健康度、计划时间、任务状态分布。
- 上述视图共用同一套口径，并在页面上写明口径，避免"看数说不同话"。

### 4. 验收与风险
- 验收闭环：通过（任务关闭）/ 驳回（退回执行，**驳回原因必填**）/ 重验；防重复提交。
- 风险台账：登记、等级（高/中/低）、负责人、状态流转与审计。
- **项目关闭阻断**：存在未关闭风险时不允许关闭项目，并给出原因汇总。

### 5. 个人工作台
- 固定五块：我的待办 / 逾期 / 待验收 / 被提及 / 近期计划。
- 逾期口径：计划结束日**次日 00:00（Asia/Shanghai）仍未关闭**即逾期（含"待验收"未关闭）。
- 「被提及」一块**如实显示未接入**（不用 0 冒充"没有"）：@提及通知来源为明确后置项。

### 6. AI 能力（人始终在环）
- **AI 需求拆解**：在故事详情生成"可人工复核的工作建议"，**生成后不会自动写入任何正式任务**；由 PM 采纳 / 修改后采纳 / 拒绝，处置写审计。页面如实标注当前执行器为**本地确定性 Stub**（无 SDK、无外部网络请求）。
- **AI 排期建议**（PM-only）：生成 → 复核（校验日期/依赖/负载）→ 采纳 / 修改后采纳 / 拒绝 → 应用正式日期 → 审计留痕。支持整份原子应用（一个任务非法则整批回滚）、幂等重放、并发冲突检测、快照过期（任务/成员/依赖/里程碑/负载任一变化即整份失效）。
- **未配置模型时明确失败**，绝不静默退回本地桩、不保存伪建议。
- 数据边界：只允许合成/演示数据外发，禁止真实凭据与个人信息；敏感对象默认不进上下文。

### 7. 通知、UML 与附件
- **站内通知**（顶栏铃铛）：五类真实来源已端到端可达 —— 任务分配、逾期、验收提交/通过/驳回、风险新建与提级、里程碑节点；实测送达延迟 2.0s / 0.08s / 1.1s（目标 ≤60 秒）。
- **在线 UML**：用例图 / 时序图编辑，节点与项目对象（目标/活动/故事/任务）关联；写权限仅 PM，受限图对非 PM 返回 404。
- **任务附件**：受限类型 + 大小上限（10MB）；任务删除时清理元数据与实体，失败可重试。

### 8. 工程基础
- 公共领域事件：业务写入与事件同事务追加，发布失败则业务回滚；幂等键；敏感事件只携带引用。
- 测试基建：每文件独立临时 SQLite；唯一 seam 为 HTTP 接口层；并行并发上限受控，消除全量偶发 `database is locked`。

| 项目 | 结果 |
|---|---|

| 端到端主旅程 | 已实跑：建目标→活动→故事→任务→AI 拆解并采纳→成员改状态并提交验收→PM 验收通过→通知送达（过程截图与数据库读数见交付物证据） |
| 端到端异常/权限旅程 | 已实跑：成员直连 PM 专属页被拒（"当前账号不能访问排期建议"）；非项目成员直连项目得 404（"项目不存在或无权访问"） |
