# 01 — 建立 Sprint 1 当前状态基线

**What to build:** 团队可以从一个更新后的状态表和交接入口，清楚看到 Sprint 1 各故事、端点、页面、分支及验收证据的当前状态，并区分设计基线、历史记录与现状。

**Blocked by:** None — can start immediately.

**Status:** draft — awaiting breakdown review.

- [ ] 为各用户故事列出当前分支/主干状态、对应接口与页面、待验证项。
- [ ] 给历史集成记录标注适用日期或提交，并指向当前状态入口。
- [ ] 更新 handoff 和前端路线说明中已经过时的占位/集成状态描述。
- [ ] 将代码注释中的主干状态描述与已注册路由相符，并说明任务敏感端点唯一归属。
- [ ] 不改写冻结契约的语义；需要变更时记录团队确认。
